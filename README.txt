KamenRiderFormChangeMod（以下、本Mod）は主に「平成仮面ライダーシリーズ」に登場するアイテムを模した
防具や武器等を追加する二次創作Modです。

本Modは未完成であり、今後新たな装備、サバイバル要素などが追加される予定です。
なお予告なしに開発を終了する可能性がありますので、ご了承ください。

対応バージョン：1.12.2

-注意
本Modは他のModとの併用を前提として制作されていませんので、他Modとの競合や不具合が発生する可能性があります。
本Modを導入することで発生したあらゆる事象に対して制作者は責任を負いかねますので、導入前のバックアップをオススメします。

マルチプレイでは複数人が同ライダーに変身したりするとモデル表示がおかしくなる場合がありますので、
非対応ではありませんが非推奨です。使用する際は理解した上でご使用ください。
※仮面ライダーギーツ系の防具のみ、マルチプレイを前提として設定を変更しています。
　そのため予期しない状況でモデル表示がされてしまう場合がありますが、設定変更による仕様となります。
